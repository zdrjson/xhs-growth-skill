# 小红书起号运营 Skill

给 AI 助手装上的一套「小红书运营顾问」知识包。装好之后，你直接跟 AI 说人话——

> 「我 300 粉，发了 12 条几乎没流量，问题出在哪？」
> 「帮我把这周的 5 条内容排出来」
> 「我这个标题能不能爆？帮我改 3 个版本」

它会按你**当前所处的阶段**给具体动作，而不是「要坚持、要真诚」这种正确的废话。

方法论蒸馏自 **[@yanliudreamer](https://x.com/yanliudreamer/articles)**（小红书 *Dreamer妍妍*，19.8 万粉，硅谷大厂 AI 产品设计负责人）公开发表的小红书系列 5 篇长文。本仓库不搬运原文，只整理其中可执行的判断与操作。

---

## 它能替你解决什么

| 你的处境 | 它会给你 |
|---|---|
| 一条还没发，卡在「我该做什么定位」 | 让你别做定位分析，直接给 10–20 条的试错清单 |
| 发了但没流量 | 从推荐机制倒推：是点击率、完播还是互动出了问题 |
| 不知道写什么 | 5 种会爆的内容类型 + 三个自检问题，套着写 |
| 有点数据了，不知道下一步 | 按 0–1000 / 1000–5000 / 5000–1万 分阶段的发布节奏和内容配比（40%/30%/30% 这种具体到百分比） |
| 想变现但没人找 | 变现的四层结构，以及为什么太早盯变现反而做不起来 |

**适合**：个人 IP、知识/职场/AI/设计类博主，从 0 起号到 1 万粉这一段。
**不适合**：纯带货号、店铺号、矩阵批量起号——原作者的经验不在这条路上，硬套会错。

## 安装

这个 Skill 就是**一个文件夹 + 几个 Markdown 文件**，没有代码、没有依赖、不联网。所以理论上任何能读文件的 AI 都能用，区别只是装法。

### Claude Code（最简单）

```bash
git clone https://github.com/zdrjson/xhs-growth-skill.git
cp -r xhs-growth-skill/xhs-growth ~/.claude/skills/
```

装完**重启 Claude Code**，然后正常提问就会自动触发。想确认装没装上，输入 `/` 看技能列表里有没有 `xhs-growth`。

> 只想给某个项目用？把 `xhs-growth` 放进项目里的 `.claude/skills/` 而不是 `~/.claude/skills/`。

### Claude 桌面版 / claude.ai 网页版

这两个地方通过设置里的 **Skills（技能）** 上传，要的是一个 zip 包：

```bash
git clone https://github.com/zdrjson/xhs-growth-skill.git
cd xhs-growth-skill && zip -r xhs-growth.zip xhs-growth
```

然后在 **Settings → Capabilities / Skills → Upload skill** 里传 `xhs-growth.zip`。

### Codex / Cursor / Windsurf / Cline 等编程类 Agent

这些工具大多不认 Skills 格式，但都认「项目里的说明文件」。把文件夹放进你的项目，再在它们各自的规则文件里加一句引用：

```bash
git clone https://github.com/zdrjson/xhs-growth-skill.git
cp -r xhs-growth-skill/xhs-growth ./xhs-growth
```

然后按你用的工具，在对应文件里加一行：

| 工具 | 写进哪个文件 |
|---|---|
| Codex | `AGENTS.md` |
| Cursor | `.cursor/rules/xhs.mdc` |
| Windsurf | `.windsurfrules` |
| Cline / Roo | `.clinerules` |

内容都一样：

```
聊到小红书运营、起号、涨粉、选题、爆款、变现时，
先读 xhs-growth/SKILL.md，再按里面的指引读对应的 references/ 文件。
```

### ChatGPT / Gemini / DeepSeek / Kimi 等聊天式 AI

不用装。两种用法，选一种：

**① 传文件**（推荐，效果最好）
把 `xhs-growth/references/` 里的 md 文件**当附件上传**，或放进 ChatGPT 的 Projects、Gemini 的 Gem、NotebookLM 的知识源。然后直接提问。

**② 直接粘**（临时用）
打开跟你处境最相关的那一个文件（对照下面的表），全选复制粘进对话框，末尾加一句：

```
以上是小红书运营方法论。我现在的情况是：___ 粉丝，已发 ___ 条，
数据最好的一条是关于 ___ 的。请按上面的方法给我具体建议。
```

一次粘一个文件就够，不用全传——每个文件 4–6 KB，塞进任何模型的上下文都绰绰有余。

## 装完怎么用

不需要背命令，正常说话即可。这类问法都能触发：

- 「我小红书为什么没流量」
- 「帮我看看这个封面标题行不行」
- 「300 粉了，接下来一周发什么」
- 「小红书多少粉可以接广告」

**给它越多现状，它给的建议越具体。** 最好一次说清这四件事：

> 现在多少粉 · 已经发了多少条 · 哪条数据最好 · 你能稳定输出的题材是什么

没有这些信息，它只能回通用答案——这一点在 SKILL.md 里是硬性要求，它会主动反问你。

## 里面装了什么

```
xhs-growth/
├── SKILL.md                     入口：判断你在哪个阶段，只加载需要的那 1–2 个文件
└── references/
    ├── 00-sources.md            出处、作者背景、这套结论的适用边界
    ├── 01-positioning.md        定位、人设、垂直度、8 个起号误区
    ├── 02-cold-start.md         推荐机制、封面标题公式、第一条与前 10 条怎么排
    ├── 03-viral-content.md      爆款公式、内容四段结构、会爆的 5 种类型
    ├── 04-rhythm-0-10k.md       内容储备节奏、0→1 万粉四阶段排期与内容配比
    └── 05-monetization-ip.md    变现四层结构、个人 IP 怎么长出来、长期主义
```

对照着挑文件用（聊天式 AI 手动粘贴时按这个选）：

| 你卡在哪 | 用哪个文件 |
|---|---|
| 还没开始，纠结定位人设 | `01-positioning.md` |
| 发了没流量、不会写标题封面 | `02-cold-start.md` |
| 不知道写什么、想做爆款 | `03-viral-content.md` |
| 有数据了，问频率和排期 | `04-rhythm-0-10k.md` |
| 问接广、报价、个人 IP | `05-monetization-ip.md` |

## 几条它会守住的判断

这些是从原文里提炼、写死在 Skill 里的立场，AI 回答时会遵守：

- **定位是跑出来的，不是想出来的。** 你纠结定位时它不会陪你分析，会让你先发 10–20 条。
- **点击率是第一关。** 封面标题的优先级高于正文，没点击内容再好都等于 0。
- **涨粉的因变量是信任，不是数据。** 1 万个认可你的人 > 100 万路人粉。
- **变现是结果不是起点。** 太早盯变现会让内容迎合市场、丢掉辨识度。
- **起号最大的敌人不是限流，是发了三篇就放弃。** 内容反馈本来就有延迟。

## 适用边界（重要）

原作者的经验建立在**知识 / 职场 / AI 类个人 IP** 赛道，且本人有硅谷大厂与哈佛背书。以下内容套用前请打折：

- 「广告报价 ≈ 粉丝数的 1/10」是该品类行情，**不是全平台通用标准**
- 她的个人经历（哈佛、Spotify 裁员、20 万粉）是案例，不是你会得到的结果保证
- 平台规则和流量分发会变，本仓库整理于 2026 年 8 月
